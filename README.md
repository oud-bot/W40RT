# Rogue Trader Crash Course (TR/EN)

Warhammer 40,000: Rogue Trader için 3 kişilik co-op başlangıç rehberi. Kavramlar Türkçe + İngilizce.
Interaktif sayfa: arama, sözlük, quiz, parti kurucu, hesaplayıcılar.

Çalıştırma: `index.html` dosyasını tarayıcıda açın (derleme gerekmez).
Yayın: Settings → Pages → Deploy from a branch → `main` / `(root)`.
